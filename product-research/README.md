# Product research — Israel import opportunities (2026-10-13)

Evidence-based investment decision system: 163 researched candidates → 50 ranked products, each with a dedicated page.

- `index.html` — executive summary, charts, sortable Top-50 database (open locally in any browser; no internet needed, charts are inline SVG)
- `products/NN-*.html` — one page per ranked product: demand evidence, suppliers, Israeli competitors, unit economics (3 scenarios), charts, regulatory/IP risk, marketing, verdict
- `top10.html` — deep dives, marketing angles, skeptical review and verdicts for the top 10
- `suppliers.html` — supplier link directory (B2B listings vs retail benchmarks)
- `strategy.html` — ₪5k / ₪20k / ₪50k investment baskets and the 30-day validation plan for the top 5
- `methodology.html` — formulas, sourced assumptions (VAT, duty, SII, freight), trend sweep, consumer problems, reviewer findings, rejected candidates
- `Top50_Product_Database.xlsx` — the 25-column database plus supplier directory, all candidates, assumptions and rejects
- `REPORT.md` — markdown companion of the above
- `data/` — machine-readable results (`top50.json`, `all_candidates.json`)
